## Background

[Editable Figma composition](https://www.figma.com/design/tFHSd2n2FsPw3rLgNT0ljC/Personal-Draft?node-id=6747-1412), on the existing DXRating page. `background.svg` contains named layers and an embedded copy of the official character artwork. It follows the previous backgrounds' decorative edges and open center, with mint, turquoise, and gold, clock dials, star constellations, sweeping musical trails, gears, spell pages, and a magic wand. The September 17 promotional references inform the blue-and-gold palace, turquoise lagoon, garden islands, cloud banks, and sparkling water. The final revision follows the user-selected Frame 2 (1626:81): a stronger turquoise field, continuous diamond grid, diagonal star trails and outlined wands, plus large central musical and magic-hat emblems. Earlier compositions remain beside it in Figma. A small clipping path removes the visible copyright text from the background export.

The web exports are checked into `apps/web/public/images/versions/magical/` so they deploy with the app. They do not depend on a separate CDN upload. The logo is a lossless WebP conversion of Sega's transparent PNG. The 1600 × 1920 WebP background remains an archival flat export; the live MAGiCAL background uses the responsive SVG scene described below.

This update changes the selected release and artwork. It does not regenerate `packages/dxdata/dxdata.json` or invent MAGiCAL chart constants. The existing catalog continues to provide its known values until the upstream data is regenerated. Rank badges reuse the existing CiRCLE PLUS artwork until MAGiCAL rank assets are available.

The central emblem pair is optically centered using the alpha-weighted centroid of its rendered strokes: (1000, 1200) on the 2000 × 2400 canvas. The group is translated by (62.49, 99.55) from the original placement, matching Figma.

## Responsive web scene

`MagicalBackground.tsx` renders 14 independently positioned SVG layers. The same-origin sprite in `apps/web/src/assets/magical-background.svg` contains the original vectors, gradients, and patterns, generated by `python3 scripts/export-magical-background.py`. Vite fingerprints the sprite and the separate character WebP; the character remains official raster artwork inside an SVG image with the original crop. There is no embedded base64 artwork and no viewport-driven React state.

The center pair uses a `400 870 1200 660` viewBox, centered on the existing optical centroid, with its container centered in the viewport. At 1100px and 600px, edge ornaments and the character move outward and fade while the center pair, diagonal pattern, and palace remain. A short-landscape adjustment keeps large foreground artwork out of the controls. Only transform and opacity transition (480ms and 320ms); CSS media queries choose the final state before hydration. On page load, the inner artwork assembles with a staggered transform/opacity entrance (0–480ms delays, 1000ms ease-out). During scrolling, a passive listener feeds a single requestAnimationFrame loop: bounded scroll velocity turns the two clocks in opposite directions and gives foreground layers a slower trailing drift. Mobile motion is halved and hidden ornaments are excluded. The loop stops at rest, when the tab is hidden, and on unmount; no React renders occur per scroll frame. Reduced motion removes entrance, scroll motion, and responsive transitions. Preference wipes capture the complete scene and suppress the entrance for that mount. Layout transforms, entrance transforms, and scroll translate/rotate properties stay separate so responsive motion remains interruptible. See [motion review](motion-review.md) for verification and limits.

Regenerate the character asset, if its source changes, with:

```sh
pnpm exec node -e "require('sharp')('docs/assets/magical/kanadera.png').webp({quality:92}).toFile('apps/web/src/assets/magical-kanadera.webp')"
```

Earlier versions retain their existing image renderer. New vector scenes can extend the background discriminator in `theme.ts` and renderer in `VersionBackground.tsx`.
